# Gotham Night Edition

Dummy Gotham news desk with a 20-year archive (2006–2026). Search copy by topic, author, and date. The search ledger tracks queries, dead ends, and result clicks in this browser (plus a seeded night-desk sample).

**Tech:** React 19, TypeScript, Vite, React Router, custom CSS (Cinzel, Libre Baskerville, Barlow Condensed). No backend — the archive is local article data; search analytics stay in `localStorage`.

```bash
npm install
npm run dev
```
